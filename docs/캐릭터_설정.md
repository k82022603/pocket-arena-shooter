# 캐릭터 설정 — 파티마 로스터

- **작성일**: 2026-09-18
- **원작**: 나가노 마모루 『파이브 스타 스토리(FSS)』 — 본 문서는 비공개·비수익 팬 게임용 2차 창작 설정이다.
- 원작 설정(제작자, 마스터, 파워게이지)은 팬 위키 기준으로 정리했고, **게임 능력치는 원작 수치를 4개 스탯으로 추상화한 창작**이다. 원작과 다른 부분은 "게임 해석"으로 표기.

## 1. 파워게이지 → 게임 스탯 변환 원칙

원작 파티마의 파워게이지는 5항목(랭크: C < B < A < 2A < 3A < VA)이다. 게임에서는 이를 다음 4개 스탯으로 압축한다.

| 게임 스탯 | 의미 | 기준값(1.0) |
|-----------|------|-------------|
| `speed` | 이동속도 배율 | 260 px/s |
| `hp` | 최대 HP | 100 |
| `damage` | 탄 1발 데미지 | 10 |
| `fireInterval` | 연사 간격(틱, 낮을수록 빠름) | 10틱 (6발/초) |
| `dash` | 대시 쿨다운(틱) / 무적 틱 | 120 / 12 |

밸런스 목표: 어떤 파티마를 골라도 1:1 승률 45~55% 구간. 스펙상 최강(클로소·라키시스)이라도 게임에선 **역할 차이**로만 표현하고 상위 호환은 만들지 않는다.

## 2. 로스터 (MVP 4종)

### 라키시스 (Lachesis) — 올라운더
| 항목 | 내용 |
|------|------|
| 원작 | Dr. 크롬 발란셰의 44번째 파티마. 세 자매(아트로포스·라키시스·클로소)의 둘째. 마스터는 아마테라스, 탑승 기체 K.O.G(나이트 오브 골드). 스펙 불명 — 통상의 파티마 범주를 넘는 존재로 묘사 |
| 게임 해석 | "측정 불가"를 **모든 스탯 평균 이상 + 대시 쿨다운 단축**으로 표현. 초보자 추천 캐릭터 |
| 스탯 | speed 1.05 / hp 100 / damage 10 / fireInterval 10 / dash 쿨 90틱·무적 12틱 |
| 색상(임시) | 금색 `#f5c542` |

### 클로소 (Clotho) — 스피드형
| 항목 | 내용 |
|------|------|
| 원작 | 발란셰 45번째 파티마, 세 자매의 막내. 파워게이지 **3A-VA-VA-3A-A** — VA는 3A를 아득히 넘는 등급으로, 스펙상 작중 최강. 마스터 콜러스 3세, 탑승 기체 준쿤 |
| 게임 해석 | VA 두 항목을 **이동속도·대시 성능**에 몰아주고, HP를 깎아 유리 대포로 |

| 항목 | 내용 |
|------|------|
| 원작 | 발란셰 43번째 파티마, 세 자매의 장녀. 파워게이지 **3A-3A-3A-3A-3A**. 파티마에게 통상 시행되는 정신 제어(마인드 컨트롤)를 받지 않은 상태로 각성. 마스터 **더글라스 카이엔**, 탑승 기체 **슈펠터**(메이유 스카의 자카와 맞선 시기 기준) |
| 게임 해석 | 올 3A의 균일함을 **화력 집중**으로 표현. 제어 없는 성격 → 연사 가속 |

| 비고 | 시기별로 마스터·기체가 바뀜(카스텔포 시절 단독으로 오제 알스큘 조종, 마도대전 이후 유판드라 리미터의 파트너). 게임에서는 카이엔·슈펠터 조합을 대표 설정으로 채택 |

## 3. 확장 후보 (설정 검수 후 추가)
- 아욱소, 메가에라, 파르테노 등 발란셰 계열
- 마스터(기사) 선택 → 파티마와의 궁합 보너스(원작: 궁합이 맞으면 기체 성능 3배 — 게임에선 +10% 정도)
- 아레나 모티프: 원작 무대(예: 카스텔포, 콜러스 대 하구다 전선)

## 4. 아트 방침
- 현재: 코드로 그린 탑다운 벡터 실루엣(`apps/web/src/game/fx/Fatima.ts`). 머리(피부 초승달+머리카락), 조준 방향을 향한 슈트 몸통·총, 이동/조준 반대로 흩날리는 머리카락, 파티마별 머리장식
  - 라키시스: 금발 롱헤어, 남색 슈트에 금색 액센트, 헤일로 링
  - 클로소: 은백색 롱헤어, 청색 슈트, 뒤로 길게 흐르는 베일 리본
  - 아트로포스: 어두운 보라 단발, 자주 슈트에 핑크 액센트, 티아라
  - 에스트: 흑발, 상징인 오렌지 슈트, 뒤통수 리본
  - 색·머리 모양은 게임 해석이며 검수 후 조정 가능
- 이후: 원작 파티마 슈트 실루엣 기반 자체 도트 스프라이트로 교체 가능(같은 인터페이스). 원작 그림·공식 일러스트를 그대로 사용/복제하지 않음 (팬 게임이라도 이미지 무단 전재는 피함)
