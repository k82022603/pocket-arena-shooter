# 캐릭터 설정 — 파티마 로스터

- **작성일**: 2026-09-18
- **원작**: 나가노 마모루 『파이브 스타 스토리(FSS)』 — 본 문서는 비공개·비수익 팬 게임용 2차 창작 설정이다.
- 원작 설정(제작자, 마스터, 파워게이지)은 팬 위키 기준으로 정리했고, **게임 능력치는 원작 수치를 4개 스탯으로 추상화한 창작**이다. 원작과 다른 부분은 "게임 해석"으로 표기.

## 1. 파워게이지 → 게임 스탯 변환 원칙

원작 파티마의 파워게이지는 5항목(랭크: C < B < A < 2A < 3A < VA)이다. 게임에서는 이를 다음 4개 스탯으로 압축한다.

| 게임 스탯 | 의미 | 기준값(1.0) |
|-----------|------|-------------|
| `speed` | 이동속도 배율 | 260 px/s |
| `hp` | 최대 HP | 100 |
| `damage` | 탄 1발 데미지 | 10 |
| `fireInterval` | 연사 간격(틱, 낮을수록 빠름) | 10틱 (6발/초) |
| `dash` | 대시 쿨다운(틱) / 무적 틱 | 120 / 12 |

밸런스 목표: 어떤 파티마를 골라도 1:1 승률 45~55% 구간. 스펙상 최강(클로소·라키시스)이라도 게임에선 **역할 차이**로만 표현하고 상위 호환은 만들지 않는다.

## 2-1. 기본 무기 선택지 (게임 창작)
타이틀에서 파티마별로 기본 무기를 고른다. 연사 간격은 파티마 고유 간격에 배율로 적용되어 캐릭터 차이가 유지된다. 아레나 픽업(산탄총·레이저)은 10초 동안 이를 덮어쓴 뒤 다시 기본 무기로 돌아온다.

| 무기 | 특성 | 사용 가능 |
|------|------|-----------|
| 라이플 | 균형 (기본값) | 전원 |
| 기관총 | 연사 2배, 위력 0.55배, 탄 흔들림 | 라키시스, 클로소, 에스트 |
| 장총 | 연사 1/3.2, 위력 2.4배, 탄속 1500 | 라키시스, 아트로포스 |
| 산탄 | 연사 1/2.8, 4발 부채꼴, 위력 0.6배/발, 짧은 사거리 | 클로소, 아트로포스, 에스트 |

- 라키시스(올라운더): 라이플 / 기관총 / 장총
- 클로소(스피드): 라이플 / 기관총 / 산탄 — 치고 빠지기
- 아트로포스(화력): 라이플 / 장총 / 산탄
- 에스트(방어): 라이플 / 산탄 / 기관총
- 1인 대전의 봇은 자기 파티마 선택지 중 무작위로 든다

## 3. 확장 후보 (설정 검수 후 추가)
- 아욱소, 메가에라, 파르테노 등 발란셰 계열
- 마스터(기사) 선택 → 파티마와의 궁합 보너스(원작: 궁합이 맞으면 기체 성능 3배 — 게임에선 +10% 정도)
- 아레나 모티프: 원작 무대(예: 카스텔포, 콜러스 대 하구다 전선)

## 4. 아트 방침 (2026-09-19 개정)
비공개 팬 게임이므로 **원작 일러스트를 그대로 사용**한다. 이미지는 사용자가 제공한 파일을 `apps/web/public/fatima/`에 둔다.

- **초상(캐릭터 선택·HUD·결과 화면)**: 원작 일러스트를 종이 질감 카드에 넣어 표시 (`game/fx/Portraits.ts`)
  - `fates-trio.webp`: 운명의 세 여신 그룹 일러스트(빨간 파티마 제복). 라키시스(우상단)·클로소(좌, 거대한 머리카락)·아트로포스(하단, 단발)를 비율 좌표로 잘라 씀
  - `est-black-knight.png`: 흑기사 시절 에스트(오렌지 후드, 검은 슈트)
  - 예비: `atropos-pink.png`(핑크 제복), `clotho-pink.png`, `est-dress.png`(오렌지 드레스/검은 코트)
- **인게임 탑다운 캐릭터**: 코드로 그린 벡터(`game/fx/Fatima.ts`)를 원작 색·형태에 맞춤
  - 세 자매 공통: 흑발, 빨간 제복에 흰 소매·어깨 라인, 이마의 푸른 보석
  - 라키시스: 길고 곧은 머리 / 클로소: 뒤로 크게 펼쳐지는 거대한 머리카락 / 아트로포스: 짧은 단발, 제복은 핑크 기운
  - 에스트: 갈색 머리, 검은 슈트, 머리를 감싸는 오렌지 후드와 흰 크라바트
- HUD·탄환 색 등 UI 액센트는 구분을 위해 파티마별 고유색(금/청/핑크/오렌지)을 유지
