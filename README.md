# Arena Shooter — 모바일 웹 2인 근거리 슈팅 게임 (FSS 팬 게임)

『파이브 스타 스토리』의 파티마를 조종하는 **비공개·비수익 2차 창작 팬 게임**입니다. 공개 배포·수익화를 하지 않습니다.

- 기획서: [docs/모바일_웹_슈팅게임_기획서.md](docs/모바일_웹_슈팅게임_기획서.md)
- 캐릭터 설정: [docs/캐릭터_설정.md](docs/캐릭터_설정.md)
- 원작 일러스트는 저작권 때문에 저장소에 포함하지 않습니다. 초상 카드를 보려면 [apps/web/public/fatima/README.md](apps/web/public/fatima/README.md)대로 이미지를 직접 넣어야 합니다 (없어도 게임은 동작)
- 블루투스 대신 Wi‑Fi(WebRTC)로 연결하는 이유와 노트북 없이 폰끼리 플레이하는 방법: [docs/연결_방식_블루투스_대신_WiFi.md](docs/연결_방식_블루투스_대신_WiFi.md)

## 구조

```
apps/web            Vite + TypeScript + Phaser 3 클라이언트
  src/sim           순수 TS 시뮬레이션 코어 (60Hz 고정 틱, 결정적 로직, PRNG, 바이너리 직렬화)
  src/net           Transport 인터페이스, WebRTC DataChannel, WebSocket 릴레이, 시그널링 클라이언트
  src/game          Phaser 씬(Boot/Title/Lobby/Arena/Result), 플로팅 가상 스틱
apps/signaling      Node + ws 시그널링/릴레이 서버 (6자리 방 코드, SDP/ICE 중계, 바이너리 릴레이)
packages/protocol   클라이언트·서버 공용 시그널링 메시지 타입
docs                기획서
```

## 실행

```bash
npm install
```

터미널 1 — 시그널링 서버 (기본 포트 8787):

```bash
npm run dev:signaling
```

터미널 2 — 클라이언트 (http, LAN 노출):

```bash
npm run dev
```

폰에서는 PC의 LAN IP로 `http://<PC-IP>:5173` 접속. 시그널링은 같은 오리진의 `/ws` 경로로 프록시되므로 별도 설정이 필요 없습니다.

카메라(QR 스캔)나 Web Bluetooth처럼 secure context가 필요한 기능을 폰에서 테스트할 때는 https로 실행합니다 (자체 서명 인증서 경고는 1회 수락):

```bash
npm run dev:https
```

타입 체크:

```bash
npm run typecheck
```

## 호스팅 (노트북 없이 폰끼리 플레이)

시그널링 서버는 방 코드와 연결 협상만 중개하므로 무료 호스팅으로 충분합니다.

1. **시그널링 → Render**: [render.yaml](render.yaml) 블루프린트. Render 대시보드 → New → Blueprint → 이 저장소 → Apply. 배포 후 `https://<이름>.onrender.com/healthz`가 `{"ok":true}`를 주면 완료. 클라이언트에는 `wss://<이름>.onrender.com`을 `VITE_SIGNALING_URL`로 준다. 무료 플랜은 15분 유휴 후 잠들어 첫 접속이 30~60초 느릴 수 있다
2. **웹 앱 → GitHub Pages** (선택, 공개 URL이 생기므로 주의): 저장소 Settings → Pages → Source "GitHub Actions", Variables에 `SIGNALING_URL` 추가, Actions 탭에서 "Deploy web to GitHub Pages" 수동 실행. 주소는 `https://<계정>.github.io/<저장소>/`. 저장소에 없는 초상 이미지는 Pages에도 없다
3. 노트북에서 개발 서버를 쓰되 시그널링만 호스팅 것을 쓰려면 `apps/web/.env`에 `VITE_SIGNALING_URL=wss://...`

## 현재 상태 (M1 초기 골격)

- 타이틀에서 파티마 4종(라키시스/클로소/아트로포스/에스트) 선택, 캐릭터별 속도·HP·화력·대시 차이 적용
- 솔로 아레나: 좌측 스틱 이동, 우측 스틱 조준+자동 발사, 대시 버튼
- PC 조작(노트북 테스트용): WASD/방향키 이동, 마우스 위치로 조준, 왼쪽 버튼 홀드 발사, Shift/Space 대시. 키보드나 마우스를 쓰는 순간 켜지고 커서가 조준점으로 바뀌며, 터치를 쓰면 스틱 조작으로 돌아간다
- 로비: 방 만들기 → 참가 링크(`?join=코드`) QR + 6자리 코드 + 링크 복사/공유. 참가는 세 가지 — 폰 기본 카메라로 QR을 찍어 링크로 열면 자동 참가, 앱 안 QR 스캐너(Chrome은 `BarcodeDetector`, 그 외는 jsQR 폴백; https 필요), 코드 직접 입력. 연결은 WebRTC DataChannel, 5초 실패 시 릴레이 폴백
- 대전 동기화 (M2, 호스트 권위): 호스트가 양쪽 입력으로 시뮬레이션을 돌리고 20Hz로 전체 스냅샷 전송. 게스트는 자기 캐릭터를 예측하고 스냅샷 ack 기준으로 재조정, 상대·탄환은 100ms 지연 보간. 게스트 입력은 틱 번호가 붙고 직전 2틱을 중복 포함해(패킷 손실 복구) 호스트 큐(최대 100ms)에서 순서대로 소비
- 발사 예측 (M3): 게스트는 발사 즉시 예측 탄환을 그리고, 탄환에 실린 "발사 입력 틱"으로 권위 스냅샷의 탄환과 대조한다. 호스트가 처리한 입력인데 스냅샷에 없으면(쿨다운 불일치, 이미 명중) 지운다
- 되감기 판정 (M3): 호스트는 게스트 탄환을 판정할 때 게스트가 보고 쏜 시점(RTT/2 + 보간 지연 100ms, 상한 200ms)의 자기 위치로 되감아 판정한다
- 협동 방어전 (M4): 타이틀에서 모드 토글. 중앙 코어(HP 500)를 10웨이브 동안 방어. 적 3종 — 척후병(플레이어 추격·접촉 피해), 포수(거리 유지·사격), 강습병(코어 직행·고체력). 웨이브 사이 3초 대기, 40틱 간격 스폰. 다운된 아군 곁에 2초 머물면 50% HP로 부활. 15초마다 힐팩(+30) 최대 3개. 코어 파괴 또는 전원 다운 시 패배. 적·픽업·코어는 스냅샷으로 동기화되고 게스트는 적 위치를 보간. 협동에서는 아군 피해 없음. 혼자 하기에서는 1인 방어
- 연출: 총구 화염·탄환 궤적·피격 플래시·격파 폭발·대시 잔상·화면 흔들림·코어 펄스·웨이브 배너. 파티마는 코드로 그린 탑다운 실루엣(`game/fx/Fatima.ts`)
- 폴리싱·PWA (M5): `vite-plugin-pwa`로 매니페스트·서비스워커 생성(오프라인 캐시, 자동 업데이트), 타이틀에 "홈 화면에 설치" 버튼(설치 가능할 때만). 아이콘은 `npm run icons`가 의존성 없이 PNG로 생성. Web Audio 합성 효과음(에셋 없음, 타이틀 🔊 토글로 음소거, 첫 터치에서 unlock). 아레나 진입 시 Wake Lock으로 화면 꺼짐 방지, 세로 화면이면 회전 안내 오버레이. 처음 3초 fps를 재서 느린 기기는 파티클 축소
- 결과 화면: 호스트 권위로 집계한 통계(명중률, 발사/명중, 가한·받은 피해, 대시, 협동은 처치·다운, 경기 시간, 코어 HP)를 스냅샷에 실어 양쪽이 같은 표를 본다. 기기 로컬 전적(대전 승패는 온라인만, 방어전 성공/실패·최고 웨이브)을 localStorage에 저장 — 공개 랭킹 없음
- 재접속 복구: 서버가 끊긴 슬롯을 15초간 토큰으로 보존하고, 클라이언트는 10초 안에 시그널링 재연결 → `rejoin` → WebRTC 재협상(실패 시 릴레이). 그동안 호스트는 시뮬레이션을 멈추고 양쪽에 "재연결 중… (n)" 오버레이. 복구되면 호스트가 캐릭터·스냅샷을 신뢰 채널로 재전송하고 게스트는 버퍼를 비운 뒤 그 시점부터 이어간다. 실패하면 남은 쪽 승리(협동은 패배)로 결과 화면
- 아레나 픽업(대전·협동 공통, `sim/weapons.ts`): 15초마다 최대 3개, 리페어 팩 40% / 스캐터 캐논 25%(부채꼴 5발·짧은 사거리·10초) / 레이저 랜스 20%(관통 광선·10초) / 이레이저 부스트 15%(5초 1.5배). 무기 상태는 스냅샷에 실려 게스트 예측(산탄 5발 포함)과 맞는다
- 1인 대전 상대 AI(`sim/bot.ts`): 거리 유지·좌우 왕복·픽업 줍기·날아오는 탄 대시 회피·오차 있는 조준·점사
- 초상: `public/fatima/`의 단독 전신 일러스트(laki2, clotho1, atropos1, est2)를 런타임에 배경 제거해 카드로 표시
- 헤드리스 규칙 검사: `npm run check:sim` (설명: [docs/테스트_방식과_헤드리스.md](docs/테스트_방식과_헤드리스.md))
- 파티마별 기본 무기 선택(타이틀): 플레임 런처/니들 스트림/버스터 런처/스캐터 건 중 파티마마다 3종. 픽업 무기가 끝나면 기본 무기로 복귀. 선택은 기기에 저장되고 캐릭터 패킷으로 상대에게 전달
- 아직 없음: 보정 스무딩, 적 대상 되감기 판정(적은 현재 위치로 판정)

네트워크 상태 실험: 게스트 탭 URL에 `?lag=120&jitter=30&loss=10` 처럼 붙이면 전송 지연·손실을 주입한다 (손실은 input 채널에만 적용).
